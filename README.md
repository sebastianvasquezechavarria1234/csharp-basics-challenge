# 🚀 C# Fundamentals - Challenge 1 (Reto 1)

Welcome to **Challenge 1**! This is a simple yet effective C# Console Application designed to demonstrate the fundamental concepts of the .NET framework. 

## 🎯 Project Overview

This project serves as an introductory exercise covering:
- 📅 **Date Formatting:** Displaying current dates in various readable formats.
- ⌨️ **User Input:** Reading and parsing data entered by the user through the console.
- 🧮 **Basic Math Operations:** Calculating the area of a triangle given its base and height.
- 💵 **Number Formatting:** Displaying numeric results in different formats such as currency, fixed-point, and general numbers.

## 🛠️ Technologies Used

- **Language:** C#
- **Framework:** .NET Console Application
- **IDE:** Visual Studio

## 🚀 How to Run

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/sebastianvasquezechavarria1234/donet.git
   ```
2. Open the `csharp-basics-challenge.sln` solution file in Visual Studio.
3. Build the solution.
4. Run the application to interact with the console prompts.

## 📋 Features

- **Date Display:** Shows the current date in both short and customized long formats.
- **Interactive Calculator:** Prompts the user to input the base and height of a triangle.
- **Formatted Output:** Outputs the calculated area using built-in C# string formatting:
  - `N2`: Number with 2 decimal places.
  - `C2`: Localized currency format.
  - `F2`: Fixed-point format.
  - `G`: General format.
